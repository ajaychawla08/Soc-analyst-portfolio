# SOC Analyst Portfolio

## About This Project

Welcome to my SOC Analyst portfolio. This repository contains cybersecurity investigation case studies created to demonstrate practical skills in security alert triage, log analysis, threat detection, and incident response.

The projects focus on analyzing security events, identifying suspicious patterns, documenting evidence, and recommending appropriate response actions.

## Skills Demonstrated

* SOC alert triage and investigation
* Windows Security Event Log analysis
* Authentication failure and suspicious login investigation
* Brute-force and password-spraying analysis
* Incident documentation and escalation recommendations
* MITRE ATT&CK mapping
* SIEM investigation concepts

## Case Studies

### 1. Windows Brute-Force Attack Investigation

Investigates repeated Windows failed logon events, identifies targeted accounts and source IP addresses, and assesses whether the activity is consistent with brute-force behavior.

**Topics:** Windows Event ID 4625, Event ID 4624, MITRE ATT&CK T1110.

[View Case Study](case-studies/windows-brute-force-investigation.md)

### 2. Password Spraying Investigation

A planned investigation into suspicious authentication attempts affecting multiple user accounts. The case study will document the evidence, authentication patterns, and investigation findings after the analysis is completed.
